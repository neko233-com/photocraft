# PhotoCraft i18n review evidence

Source commit: `0297a247a1fc2d5752335351885d3f3acd1d932e`. Original offscreen Windows captures of synthetic blank
PhotoCraft documents, 1440 x 900 points, scale 1. CPU canvas, DX12 Microsoft Basic
Render Driver, installed system fonts; no font files or personal photos included.

The language captures switch en -> zh-hans -> ja -> ko -> ru -> fr in the same shell
before the final capture. fr-brush.png covers translated/elided dynamic brush sections.
fr-pack.png covers a supplied session pack. fr-file-reload.png watches an actual external
TSV: its File label changes after Preferences opens in one running process, and the
inspection generation advances 1 -> 2 with no error.
