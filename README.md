# PhotoCraft i18n review screenshots

Original offscreen captures of synthetic blank PhotoCraft documents on Windows,
1440 x 900 points, scale 1, with installed system fonts. Licensed MIT OR Apache-2.0.
No font files or personal photos are included.

Source commit: 6e7c9c2078d0b8996cbfb12aa1a5df30c39a7086
Each language view uses Preferences > Interface. The script switches through
en, zh-hans, ja, ko, ru and fr in one running shell before the final capture.
fr-brush.png also exercises translated and elided dynamic brush section titles.

English is the reference view; the other captures show the language switched at runtime.
